# Akin

Portfolio site for Akintunde Rufai, exported from the Framer site https://akintunde.framer.website.

- Pages: `index.html`, `about.html`, `experiments.html` (Motion), `resume.html`, `clane.html`, `cedar.html`, `salario.html`, `thesiora.html` (served at clean URLs like `/clane` via `vercel.json`), `404.html`
- `assets/site.js` reproduces the Framer interactions (appear animations, hover/click states, About slider, autoplay videos, hero gradient)
- `assets/site.css` small overrides
- Images, videos and fonts load from Framer's CDN (framerusercontent.com).

Deployed on Vercel: https://akin-six.vercel.app
