# akindevdesign

Portfolio site for Akintunde Rufai — plain HTML, CSS and JS (no build step).

```
index.html
css/style.css
js/main.js
assets/        ← add your images here
```

## Images
Export these from Framer and drop them into `assets/` (styled placeholders show until you do):

- `avatar.jpg` — profile photo
- `cedar.png`, `salario.png`, `thesiora.png`, `clane.png` — project thumbnails (4:3 works best)

## Interactive effects
Letter-by-letter hero title, mouse-following hero glow, sliding nav pill, magnetic buttons,
3D tilt + light sweep on project cards with a "View" cursor bubble, staggered scroll reveals,
scroll progress bar, dark-mode toggle, and click-to-copy email with toast.

## Run locally
Open `index.html` in a browser, or `npx serve .`
